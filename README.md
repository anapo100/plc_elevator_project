# 🛗 Elevator_PLC_Control

5층 건물 엘리베이터를 PLC (Programmable Logic Controller)로 제어하는 프로젝트
LS산전 XGI 시리즈 PLC와 XG5000 (Ladder Logic)을 활용하여 다중 호출 처리, 문 제어, 비상정지 등 실제 엘리베이터 운행 로직을 구현하고, C# 기반 HMI 화면과 실시간 통신으로 연동합니다.

<br/>

## 📌 프로젝트 개요

본 프로젝트는 5층 건물 엘리베이터의 자동 제어 시스템을 PLC 기반으로 설계하고, WPF HMI 화면과 통합하여 실시간 모니터링 및 조작이 가능한 데모 시스템을 구현합니다.

### 주요 목표

- 큐(Queue) 기반 다중 호출 처리 알고리즘 구현
- 비상정지 및 인터락(Interlock) 안전 기능 내장
- 층 표시등 및 방향 표시등 실시간 출력 제어
- WPF HMI와 PLC 간 실시간 상태 동기화

### 핵심 기능

- 외부 호출(층별 상승/하강) + 내부 목적지 버튼 통합 처리 (8 + 8 입력)
- 방향 우선 스케줄링 알고리즘으로 효율적인 다중 호출 처리
- 문 열림/닫힘 타이머 제어 및 수동 개입 지원
- 비상정지 시 이동·큐 초기화 후 정상 복귀
- WPF 화면에서 현재층, 목표층, 방향, 문 상태, 통신 상태 실시간 확인

<br/>

## 🗺️ PLC 메모리맵

PLC와 WPF HMI는 동일한 메모리맵 구조를 공유하여 상태를 실시간으로 동기화합니다.

| 구역 | 메모리 주소 | 역할 |
|------|------------|------|
| **상태** | MW0 ~ MW3 | 현재층 / 목표층 / 방향 / 운행 상태 |
| **호출 큐** | MB10 ~ MB12 | 외부 상승 / 외부 하강 / 내부 목적지 |
| **안전 플래그** | MB20 | 비상정지 / 문 상태 / 이동 가능 |
| **WPF 입력** | MB30 ~ MB31 | 외부 호출 / 내부 버튼 / 문 제어 / 비상정지 |

<br/>

## ⚙️ 제어 로직

### 핵심 타이머

| 타이머 | 설정 시간 | 역할 |
|--------|----------|------|
| T0 | 3초 | 문 열림 유지 |
| T1 | 2초 | 문 열리는 동작 완료 |
| T2 | 2초 | 문 닫히는 동작 완료 |
| T4 | 2초 | 층간 이동 |

### 인터락 조건

- 문이 열려 있는 동안 이동 불가
- 비상정지 활성화 시 모든 동작 즉시 중단
- 이동 중 문 열기 명령 무시

<br/>

## 🖥️ WPF HMI 화면 구성

| 패널 | 표시 정보 |
|------|----------|
| **내부 제어 패널** | 목적지 선택, 문 열기/닫기, 비상정지 입력 |
| **운행 상태 요약** | 현재층, 목표층, 상태, 방향, 문 상태, 통신 상태 |
| **외부 호출 / 큐 LED** | 층별 호출 입력과 큐 상태를 동시에 확인 |
| **통신 완료 포인트** | 버튼 입력과 상태 반영이 즉시 이어짐 |

<br/>

## 🧪 대표 시연 시나리오

| 시나리오 | 입력 | PLC 반응 | 화면 변화 |
|---------|------|----------|----------|
| **다중 호출 처리** | 1층에서 4층 선택 후 3층 외부 상승 호출 추가 | 큐 통합 → 방향 우선 처리 → 3층 선처리 | 큐 LED 변화, 현재층 갱신, 상태 전환 |
| **문 수동 개입** | 도착 후 문 열기 / 문 닫기 버튼 입력 | T0 유지 시간 조절 또는 즉시 닫힘 전환 | 문 애니메이션과 상태 카드 변화 |
| **비상정지 / 해제** | 이동 중 비상정지 후 해제 입력 | 이동·큐 초기화 → 정상 대기 복귀 | 비상 상태 강조 → 정상 복귀 표시 |
